**HU \- 009\. Gestión del perfil de usuario registrado.**

**1.1 *Descripción***  
Como usuario **registrado**, **quiero** poder acceder y gestionar mi perfil personal, **para** mantener mi información actualizada

***1.2 Criterios de aceptación.***  
A continuación, en la siguiente tabla, se indican los criterios de aceptación de la correspondiente historia de usuario.

| Núm.criterio | Descripción |
| ----- | ----- |
|  1 |  Como usuario registrado puedo solicitar abrir mi perfil   desde la app. |
|  2 |  Como usuario registrado, puedo consultar mis datos   personales guardados (nombre, correo electrónico, etc.) |
|  3 |  Como usuario registrado puedo modificar mis datos   personales. |
|  4 |  Como usuario registrado puedo cambiar mi correo   electrónico de acceso al sistema. |
|  5 |  El sistema valida los nuevos datos antes de   guardarlos (formato correcto de correo, longitud de   contraseña, etc.) |
|  6 |  El sistema muestra un mensaje de confirmación  cuando los cambios se guardan correctamente. |
|  7 |  El sistema protege los datos personales del usuario   registrado. |

La información necesaria para esta historia de usuario se muestra en la siguiente tabla.

| Nombre | Tipo | Longitud | Formato |
| ----- | ----- | ----- | ----- |
|  idUsuario |  Cadena de caracteres |  6-12 |  Alfanumérico |
|  Nombre |  Cadena de caracteres |  1-50 |  Texto |
|  Correo |  Cadena de caracteres |  1-100 |  Formato correo |
|  Contraseña |  Cadena de caracteres |  8-20 |  Alfanumérico con   mayúsculas y números |
|  Última modificación |  Cadena de caracteres |  19 |  dd/mm/aaaa hh:mm:ss |

***1.3 Discusiones posteriores***  
No hay discusiones posteriores.
