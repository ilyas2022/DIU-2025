**HU \- 012\. Iniciar sesión de un usuario registrado**

***1.1 Descripción***  
**Como usuario registrado**, **quiero** poder iniciar sesión en la web o aplicación móvil, **para** poder acceder a mis datos personales, bonos activos, rutas favoritas y demás funcionalidades personalizadas del sistema.

***1.2 Criterios de aceptación***  
A continuación, en la siguiente tabla, se indican los criterios de aceptación de la correspondiente historia de usuario.

| Núm.criterio | Descripción |
| ----- | ----- |
|  1 |  Como usuario registrado puedo solicitar iniciar    sesión. |
|  2 |  El sistema solicita las credenciales de acceso (correo   electrónico y contraseña). |
|  3 |  El sistema valida que las credenciales introducidas   sean correctas. |
|  4 |  Si las credenciales son válidas, el sistema permite el   acceso al perfil del usuario. |
|  5 |  Si las credenciales son incorrectas, el sistema   muestra un mensaje de error. |
|  6 |  El sistema ofrece la opción de “¿Olvidaste su   contraseña?”. |
|  7 |  El usuario puede cerrar sesión en cualquier momento   desde su perfil. |

La información necesaria para esta historia de usuario se muestra en la siguiente tabla.

| Nombre | Tipo | Longitud | Formato |
| ----- | ----- | ----- | ----- |
|  idUsuario |  Cadena de caracteres |  6-12 |  Alfanumérico |
|  Correo |  Cadena de caracteres |  1-100 |  Formato correo |
|  Contraseña |  Cadena de caracteres |  8-20 |  Alfanumérico con   mayúsculas y números |
|  Fecha acceso |  Cadena de caracteres |  19 |  dd/mm/aaaa hh:mm:ss |
|  Estado sesión |  Enumerado |  \- |  Activa / Cerrada / Error |
