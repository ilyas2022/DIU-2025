**HU \- 005\. Consultar líneas y paradas de autobuses**

***1.1 Descripción***  
**Como usuario (registrado o no registrado)**, **quiero** consultar todas las líneas y paradas de autobuses disponibles **para** conocer toda la información de las rutas, identificar dónde puedo subir y bajar, y planificar los desplazamientos.

***1.2 Criterios de aceptación***  
A continuación, en la siguiente tabla, se indican todos los criterios de aceptación de esta historia de usuario.

| Núm.criterio | Descripción |
| ----- | ----- |
|  1 |  Como usuario puedo explorar el catálogo de líneas y   paradas. |
|  2 |  El sistema muestra la lista completa de líneas con su   nombre y destino principal |
|  3 |  El usuario puede seleccionar una línea y ver todas las   paradas que incluye en orden de recorrido, así como los    tiempos estimados de llegada de esa línea a las diferentes   paradas que la forman. |
|  4 |  El sistema ofrece un buscador para localizar una línea    concreta por nombre de forma más rápida. |

La información necesaria para esta historia de usuario se muestra en la siguiente tabla.

| Nombre | Tipo | Longitud | Formato |
| ----- | ----- | ----- | ----- |
|  idLinea |  Numérico |  1-6 |  Entero |
|  Nombre Línea |  Cadena de caracteres |  1-50 |  Texto |
|  idParada |  Numérico |  1-6 |  Entero |
|  Nombre Parada |  Cadena de caracteres |  1-50 |  Texto  |
| Destino Principal |  Cadena de caracteres  |  1-100 |  Texto |
