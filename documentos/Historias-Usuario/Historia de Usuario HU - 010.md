**HU \- 010\. Ver mapa completo de todas las líneas y paradas**

**1.1 *Descripción***  
**Como usuario (registrado o no registrado)**, **quiero** visualizar todas las líneas y paradas disponibles en un mapa, **para** conocer fácilmente la ubicación de cada parada y las rutas que recorren los autobuses.

***1.2 Criterios de aceptación.***  
A continuación, en la siguiente tabla, se indican los criterios de aceptación de la correspondiente historia de usuario.

| Núm.criterio | Descripción |
| ----- | ----- |
|  1 |  Como usuario puedo solicitar ver el mapa completo   de líneas y paradas. |
|  2 |  El sistema muestra una imagen del mapa con todas   las líneas de autobuses representadas. |
|  3 |  El usuario puede ampliar o reducir la imagen para   visualizar mejor las zonas. |
|  4 |  La información del mapa se actualiza cuando   cambian las rutas o paradas. |

La información necesaria para esta historia de usuario se muestra en la siguiente tabla.

| Nombre | Tipo | Longitud | Formato |
| ----- | ----- | ----- | ----- |
|  idMapa |  Cadena de caracteres |  1-10 | Alfanumérico |
|  URLImagen |  Cadena de caracteres | 1-200 | PGN / JPG |
|  Fecha Actualización |  Cadena de caracteres |  19 |  dd/mm/aaaa hh:mm:ss |
